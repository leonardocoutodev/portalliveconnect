# V4.1 — Frontend do Editor 360°

Arquivo principal alterado no pacote de release:
- `assets/js/v360/admin-central.js`
- `assets/css/responsive.v370.css`
- `build.json`

## Navegação

O botão **Editar tudo** foi adicionado em:
- Secretaria > Alunos e matrículas;
- Comercial > Leads / funil;
- Comercial > Jovem Aprendiz.

## Tela

O editor carrega `admin_student_editor_get` e apresenta:
1. cadastro completo do aluno;
2. dados de responsável;
3. estado do CRM e score;
4. dados de Jovem Aprendiz quando existirem;
5. origem/UTMs em seção avançada;
6. formulário para adicionar novo curso;
7. um editor independente para cada enrollment do aluno.

## Comportamento de curso

Ao mudar o curso de um enrollment:
- a turma é revalidada;
- os valores antigos não são enviados pelo frontend;
- o backend recalcula a precificação vigente;
- a tela é recarregada para revisão financeira.

Em uma segunda gravação, qualquer valor financeiro pode ser ajustado manualmente.

## Histórico

Encerrar curso utiliza cancelamento lógico e mantém o enrollment no histórico. Restaurar reaproveita o vínculo encerrado quando permitido pelas regras existentes.

## Responsividade

Foram adicionadas classes específicas para cards de enrollment, ações e seção avançada, incluindo tratamento mobile.
