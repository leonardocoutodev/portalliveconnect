# Live Connect Portal V5.10.2 — boas-vindas proativas do Lico

## Comportamento
- Exibe uma mensagem de boas-vindas cerca de 1,8 s após o acesso ao Portal.
- Exibe uma vez por sessão do navegador.
- Clique na mensagem abre o Lico.
- Some automaticamente após 10 s ou pode ser fechada.
- Não força a abertura do painel completo.

## Texto contextual
- Home: ajuda para encontrar a formação certa.
- Página de curso: oferece explicar o curso, horários, valores e matrícula.
- Gratuitos: oferece ajuda para escolher curso gratuito.
- Jovem Aprendiz: oferece explicar funcionamento e inscrição.

## Preservado
- Enter envia.
- Shift + Enter quebra linha.
- Portal com deploy manual na KingHost.
- Admin permanece separado no Cloudflare Workers.
