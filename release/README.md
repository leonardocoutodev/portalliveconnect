# Pacotes de produção

## Admin Live Connect

Destino oficial:

`https://admin.liveconnectios.workers.dev/`

Versão de referência:

**V5.0 — Produto, UI e UX**

A V5.0 substitui a camada visual acumulada das versões anteriores por um design system exclusivo do Admin.

Principais entregas:
- shell administrativo reconstruído;
- sidebar sem deslocamento duplicado;
- navegação recolhível;
- Home orientada a prioridades;
- tabelas desktop/mobile revisadas;
- Editor Visual e Cadastro 360° preservados;
- busca global server-side;
- Leads com busca, filtro e paginação server-side;
- mensagens técnicas traduzidas para linguagem operacional;
- 0 `!important` no novo design system;
- CSS público do Portal removido do runtime do Admin.

O pacote manual para Cloudflare é:
`Live_Connect_ADMIN_V5.0_PRODUTO_UI_UX.zip`.

## Portal público

O Portal permanece separado. A V5.0 do Admin não exige alteração do Portal público.
